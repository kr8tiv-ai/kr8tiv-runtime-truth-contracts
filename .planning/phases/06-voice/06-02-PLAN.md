<objective>
Add streaming TTS that delivers audio chunks as sentences are synthesized, achieving under 1 second latency from text availability to first audio byte.

Purpose: Waiting for full response text before TTS makes voice interaction feel sluggish. Streaming sentence-by-sentence with crossfade creates natural conversational flow — the companion starts speaking while still "thinking" about the rest.

Output: Streaming TTS engine with sentence chunking, audio crossfade, and WebSocket/SSE API endpoints.
</objective>

    - splitIntoSentences returns single-element array for short text under 80 chars with no sentence boundary
    - crossfadeChunks merges two WAV buffers with 50ms linear crossfade at the boundary
    - StreamingTts.streamSynthesize yields SynthesisResult chunks as an AsyncGenerator
    - StreamingTts.streamSynthesize processes sentences in parallel with concurrency limit of 2 (synthesize next while current plays)
    - StreamingTts emits "chunk" events with {index, audio, sentence, isLast} payloads
  </behavior>
  <action>
    Create voice/audio-chunker.ts:
    - splitIntoSentences(text: string): string[] — Split on sentence boundaries (. ! ? followed by space or end). Handle abbreviations by checking against a set of known patterns (Mr., Mrs., Dr., Sr., Jr., U.S., etc.). Minimum chunk length 10 chars to avoid splitting on period in "v2.0".
    - crossfadeChunks(chunk1: Buffer, chunk2: Buffer, overlapMs: number = 50): Buffer — For WAV format, apply linear crossfade over the overlap region. If chunks are not WAV (no RIFF header), just concatenate.

    Create voice/streaming-tts.ts:
    - StreamingTtsConfig: { pipeline: VoicePipeline, companionId: string, concurrency?: number (default 2), onChunk?: callback }
    - class StreamingTts extends EventEmitter:
      - constructor(config: StreamingTtsConfig)
      - async *streamSynthesize(text: string): AsyncGenerator<SynthesisResult & { index: number, sentence: string, isLast: boolean }>
        - Split text into sentences
        - For each sentence, call pipeline.synthesize(sentence, companionId)
        - Yield each result as it completes
        - Use a sliding window: start synthesizing sentence N+1 while yielding sentence N
        - Emit "chunk" event for each yielded result
        - Emit "done" event when all sentences processed
      - async synthesizeAll(text: string): Promise<Buffer> — convenience method that collects all chunks, crossfades them, returns single buffer

    Write tests first (RED) then implement (GREEN). Mock pipeline.synthesize.
