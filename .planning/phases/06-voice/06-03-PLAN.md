    - VoiceModeManager.setMode(userId, "local") persists and subsequent getMode returns "local"
    - VoiceModeManager.setMode(userId, "premium") persists and maps to ElevenLabs provider
    - VoiceModeManager.getTtsProvider("text-only") returns null (no TTS)
    - VoiceModeManager.getTtsProvider("local") returns "kokoro"
    - VoiceModeManager.getTtsProvider("premium") returns "elevenlabs"
    - ResponseRouter.shouldSpeak({inputMethod: "voice", voiceMode: "local"}) returns true
    - ResponseRouter.shouldSpeak({inputMethod: "text", voiceMode: "local"}) returns false
    - ResponseRouter.shouldSpeak({inputMethod: "text", voiceMode: "local", forceSpeak: true}) returns true (speaker icon override)
    - ResponseRouter.shouldSpeak({inputMethod: "voice", voiceMode: "text-only"}) returns false (mode overrides input)
  </behavior>
  <action>
    Create voice/voice-mode-manager.ts:
    - type VoiceMode = "text-only" | "local" | "premium"
    - VoiceModeConfig: { defaultMode: VoiceMode, storage: "memory" | "sqlite" }
    - class VoiceModeManager:
      - private modes: Map<string, VoiceMode> (in-memory cache, sqlite backing optional)
      - getMode(userId: string): VoiceMode — returns stored mode or defaultMode ("text-only")
      - setMode(userId: string, mode: VoiceMode): void — validates mode, stores
      - getTtsProvider(mode: VoiceMode): VoiceConfig["ttsProvider"] | null
        - "text-only" -> null
        - "local" -> "kokoro"
        - "premium" -> "elevenlabs"
      - getAvailableModes(): VoiceMode[] — returns ["text-only", "local", "premium"]

    Create voice/response-router.ts:
    - type InputMethod = "voice" | "text"
    - type ResponseMode = { speak: boolean, showText: boolean, provider: VoiceConfig["ttsProvider"] | null }
    - class ResponseRouter:
      - constructor(modeManager: VoiceModeManager)
      - shouldSpeak(params: { inputMethod: InputMethod, voiceMode: VoiceMode, forceSpeak?: boolean }): boolean
        - If voiceMode is "text-only" AND forceSpeak is not true -> false
        - If forceSpeak is true -> true (speaker icon override)
        - If inputMethod is "voice" -> true (smart matching per CONTEXT.md)
        - If inputMethod is "text" -> false
      - getResponseMode(params): ResponseMode
        - speak: shouldSpeak(params)
        - showText: always true (text always shown per CONTEXT.md)
        - provider: modeManager.getTtsProvider(voiceMode) when speak=true, else null

    Write tests first covering all behavior cases above.
  </action>
