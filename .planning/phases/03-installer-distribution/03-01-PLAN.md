**installer/src-tauri/src/main.rs:**
```rust
mod sidecar;

fn main() {
    tauri::Builder::default()
        .plugin(tauri_plugin_shell::init())
        .invoke_handler(tauri::generate_handler![
            sidecar::start_ollama,
            sidecar::stop_ollama,
            sidecar::ollama_health,
        ])
        .run(tauri::generate_context!())
        .expect("error while running KIN");
}
```

**installer/src-tauri/src/sidecar.rs:**
- `#[tauri::command] async fn start_ollama(app: tauri::AppHandle) -> Result<String, String>` -- spawns Ollama sidecar via `app.shell().sidecar("binaries/ollama")` with args `["serve"]`, stores child process handle in a global `Mutex<Option<CommandChild>>`. Returns `"started"` or error message.
- `#[tauri::command] async fn stop_ollama() -> Result<String, String>` -- kills the stored child process. Returns `"stopped"`.
- `#[tauri::command] async fn ollama_health() -> Result<bool, String>` -- sends GET to `http://localhost:11434/` using reqwest. Returns `true` if 200, `false` otherwise. Timeout: 2 seconds.
- Use `tokio::sync::Mutex` for the child process handle (not std::sync::Mutex -- async context).
- On sidecar start, wait up to 10 seconds polling health every 500ms before returning success.
- Log all sidecar lifecycle events via `log::info!`.

**installer/src-tauri/binaries/.gitkeep:**
- Empty file. Add a comment in a README or the .gitkeep itself noting: "Place ollama-{target-triple} binary here. Download from https://ollama.com/download"

Do NOT bundle the actual Ollama binary in git. It is ~50MB and platform-specific.
