  CREATE TABLE IF NOT EXISTS memories (

    content TEXT NOT NULL,
    category TEXT NOT NULL CHECK(category IN ('fact', 'preference', 'skill', 'project', 'relationship')),

- `export async function extractMemories(messages: Message[], companionId: string): Promise<Memory[]>`:
  This is the core extraction logic. It analyzes recent conversation messages to identify memorizable facts.

  **Extraction rules (pattern-based, no LLM call needed):**
  1. **Facts**: User messages containing "I am", "I'm", "my name is", "I work", "I live", "I use", "I have" -- extract the statement. Category: 'fact', importance: 0.7
  2. **Preferences**: User messages containing "I like", "I prefer", "I want", "I hate", "I don't like", "I love", "favorite" -- extract preference. Category: 'preference', importance: 0.6
  3. **Skills**: User messages mentioning specific technologies or asking about them repeatedly (detect patterns: "I'm building", "I'm working on", "my project", "my app"). Category: 'skill', importance: 0.5
  4. **Projects**: User messages containing "my project", "I'm building", "my app", "my site", "my repo" -- extract project reference. Category: 'project', importance: 0.8
  5. **Relationships**: User mentions of people ("my boss", "my team", "my friend", "[Name] said"). Category: 'relationship', importance: 0.4

  For each extraction:
  - Clean the content to a concise statement (e.g., "I'm a React developer" -> "User is a React developer")
  - Deduplicate: check existing memories via searchMemories before storing (if similar content exists with >80% word overlap, skip)
  - Store via storeMemory
  - Return array of newly created memories

- `export async function getRelevantMemories(companionId: string, currentMessage: string, limit?: number): Promise<string[]>`:
  - Search memories matching keywords from currentMessage
  - Also fetch top 5 most important memories (always relevant)
  - Combine, deduplicate, sort by importance
  - Return as string array (memory.content values) ready for injection into buildSystemPrompt

**installer/src/lib/services/learning.ts:**
- Import { Memory, getRecentMemories, searchMemories } from './memory'

- Define interface:
  ```typescript
  export interface LearningHint {
    type: 'new_memory' | 'recall' | 'insight';
    content: string;           // Human-readable hint text
    memories: Memory[];        // Related memories
    confidence: number;        // 0-1, how relevant this hint is
  }
  ```

- `export function shouldShowHint(messageCount: number, lastHintAt: number): boolean`:
  - Show a hint every 5-8 messages (not every message -- that's annoying)
  - Don't show if last hint was less than 3 messages ago
  - Show on first message of a new session if there are relevant memories from past sessions
  - Return true/false

- `export async function generateLearningHint(companionId: string, currentMessage: string, messageCount: number): Promise<LearningHint | null>`:
  - If messageCount === 1 (first message): check for recent memories. If >3 exist, create a 'recall' hint: "I remember you mentioned {memory.content}. How's that going?"
  - If messageCount % 6 === 0 (periodic): fetch recent memories, create 'insight' hint connecting 2+ related memories: "I've noticed you're working on {project} and prefer {preference}. Want me to keep that in mind?"
  - After a new memory is extracted: create 'new_memory' hint: "Noted: {memory.content}"
  - Return null if no hint is appropriate (shouldShowHint returns false, or no relevant memories)
  - Confidence: 0.9 for new_memory (just extracted), 0.7 for recall (past session), 0.5 for insight (pattern connection)
