**installer/src/lib/stores/chat.ts:**
- Import { writable, derived } from 'svelte/store'
- Import services: streamChat, abortChat, checkOllamaHealth from ollama.ts
- Import database: createConversation, listConversations, getMessages, saveMessage
- Import persona: getCompanionConfig, COMPANIONS
- Import types: ChatState, Message, Conversation, StreamChunk, Bloodline
- Create `chatStore = writable<ChatState>({ conversations: [], activeConversationId: null, messages: [], isGenerating: false, error: null, tokensPerSecond: 0 })`
- Export actions (functions that update the store):
  - `async function loadConversations(bloodline: Bloodline)`: calls listConversations, updates store.conversations
  - `async function loadConversation(conversationId: string)`: calls getMessages, updates store.messages and activeConversationId
  - `async function newConversation(bloodline: Bloodline)`: calls createConversation, adds to store.conversations, sets as active, clears messages
  - `async function sendMessage(content: string, bloodline: Bloodline, vramGb: number)`:
    1. Create user Message object with UUID (use crypto.randomUUID()), add to store.messages
    2. Save user message to database via saveMessage
    3. Create placeholder assistant Message with isStreaming=true, add to store.messages
    4. Set store.isGenerating = true
    5. Get companionConfig via getCompanionConfig(bloodline, vramGb)
    6. Build messages array from store.messages (excluding the streaming placeholder)
    7. Call streamChat(companionConfig, messagesForApi) -- iterate async generator
    8. For each StreamChunk: append chunk.content to the assistant message's content in the store, update tokensPerSecond if available
    9. On completion (chunk.done=true): set isStreaming=false, save assistant message to database, set isGenerating=false
    10. On error: set store.error, set isGenerating=false
  - `function stopGeneration()`: calls abortChat(), sets isGenerating=false
