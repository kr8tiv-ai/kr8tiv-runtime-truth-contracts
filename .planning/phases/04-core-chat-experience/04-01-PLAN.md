**installer/src/lib/types/chat.ts:**
```typescript
export interface Message {
  id: string;                    // UUID v4
  conversationId: string;
  role: 'user' | 'assistant' | 'system';
  content: string;
  modelUsed: string;             // e.g. 'local:gemma4-31b-q4' or 'frontier:claude-opus-4'
  tokensUsed: number;
  createdAt: string;             // ISO 8601
  isStreaming?: boolean;         // true while tokens are arriving
}

export interface Conversation {
  id: string;                    // UUID v4
  title: string;
  companionId: string;           // which bloodline/companion
  createdAt: string;
  updatedAt: string;
  messageCount: number;
  lastMessage?: string;          // preview text
}

export interface StreamChunk {
  content: string;               // partial token text
  done: boolean;                 // true when generation complete
  tokensGenerated?: number;
  tokensPerSecond?: number;
}

export interface ChatState {
  conversations: Conversation[];
  activeConversationId: string | null;
  messages: Message[];
  isGenerating: boolean;
  error: string | null;
  tokensPerSecond: number;
}
```

**installer/src-tauri/src/database.rs:**
- Use `rusqlite` crate (add to Cargo.toml: `rusqlite = { version = "0.31", features = ["bundled"] }`)
- On init, create database at app data dir: `{app_data}/kr8tiv/kin.db`
- Schema migration on startup (run CREATE TABLE IF NOT EXISTS):
  ```sql
  CREATE TABLE IF NOT EXISTS conversations (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL DEFAULT 'New Conversation',
    companion_id TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    message_count INTEGER NOT NULL DEFAULT 0,
    last_message TEXT
  );

  CREATE TABLE IF NOT EXISTS messages (
    id TEXT PRIMARY KEY,
    conversation_id TEXT NOT NULL REFERENCES conversations(id),
    role TEXT NOT NULL CHECK(role IN ('user', 'assistant', 'system')),
    content TEXT NOT NULL,
    model_used TEXT NOT NULL DEFAULT 'local',
    tokens_used INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL
  );

  CREATE INDEX IF NOT EXISTS idx_messages_conversation ON messages(conversation_id, created_at);
  ```
- Tauri commands (all prefixed `db_`):
  - `#[tauri::command] fn db_create_conversation(companion_id: String) -> Result<String, String>` -- creates conversation with UUID, returns JSON of Conversation
  - `#[tauri::command] fn db_list_conversations(companion_id: String) -> Result<String, String>` -- returns JSON array of Conversations, ordered by updated_at DESC, limit 50
  - `#[tauri::command] fn db_get_messages(conversation_id: String) -> Result<String, String>` -- returns JSON array of Messages, ordered by created_at ASC
  - `#[tauri::command] fn db_save_message(conversation_id: String, role: String, content: String, model_used: String, tokens_used: i32) -> Result<String, String>` -- inserts message, updates conversation.updated_at and message_count, returns JSON of Message
  - `#[tauri::command] fn db_delete_conversation(conversation_id: String) -> Result<(), String>` -- deletes conversation and all its messages
- Use a global `Mutex<Connection>` for the SQLite connection (single-writer is fine for desktop app)
- Initialize database in a `pub fn init_database(app_handle: &tauri::AppHandle) -> Result<(), String>` called from main.rs setup

**installer/src/lib/services/ollama.ts:**
- Import { StreamChunk } from '../types/chat'
- Import { CompanionConfig } from '../types/companion'
- `const OLLAMA_BASE = 'http://localhost:11434'`
- `export async function checkOllamaHealth(): Promise<boolean>` -- GET to OLLAMA_BASE, return true if 200, false on any error. Timeout 3 seconds.
- `export async function listModels(): Promise<string[]>` -- GET /api/tags, return array of model names
- `export async function* streamChat(config: CompanionConfig, messages: Array<{role: string, content: string}>): AsyncGenerator<StreamChunk>`:
  - POST to `${OLLAMA_BASE}/api/chat` with body:
    ```json
    {
      "model": config.companion.modelId,
      "messages": [{"role": "system", "content": config.systemPrompt}, ...messages],
      "stream": true,
      "options": {
        "temperature": config.temperature,
        "top_p": config.topP,
        "repeat_penalty": config.repeatPenalty,
        "num_ctx": config.contextWindow
      }
    }
    ```
  - Read response body as ReadableStream
  - Parse each newline-delimited JSON chunk from Ollama's streaming format
  - Each chunk: `{ "message": { "content": "token" }, "done": false }` or `{ "done": true, "eval_count": N, "eval_duration": N }`
  - Yield `StreamChunk` for each parsed chunk
  - Calculate tokensPerSecond from eval_count / eval_duration on the final chunk
  - Handle fetch errors gracefully: yield a StreamChunk with done=true and content="" on error, log to console
- `export async function abortChat(): void` -- stores an AbortController reference in module scope, calls .abort() to cancel in-flight generation. The streamChat function should accept an AbortSignal parameter.
